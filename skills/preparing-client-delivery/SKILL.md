# Preparing Client Delivery

## Core rule

Delivery packaging may be autonomous; consequential delivery actions require the authority of the target system and applicable approval policy.

## Workflow

- Consume only verified/accepted artifacts.
- Package the exact requested files, links, notes, and evidence.
- State known limitations or unresolved items without hiding them.
- Avoid unsupported completion, deployment, adoption, or performance claims.
- Distinguish `prepared-for-delivery` from `delivered`.
- Use `routing-human-approval` before external sends/submissions when required.

## Output

Return the delivery package, recipient/target context if known, artifact/version identifiers, verification evidence, and delivery authority status.
