# Preparing Applications

## Core rule

Every material capability, metric, customer, deployment, integration, timeline, and portfolio claim must be supportable by evidence or explicitly framed as proposed work.

## Workflow

- Consume the qualified requirements and research findings.
- Select only relevant, verifiable portfolio evidence.
- Describe the execution approach using capabilities BuildGraph can actually resolve.
- Avoid invented experience, outcomes, URLs, integrations, users, or production status.
- Surface assumptions that affect price, scope, timing, or acceptance.
- Route submission or bidding through `routing-human-approval` when the platform or policy requires it.

## Output

Return application content, evidence links/references, assumptions, unresolved questions, and submission authority status.
