# Researching Opportunities

## Core rule

Separate sourced facts, user-provided facts, and inference. Research exists to reduce execution uncertainty, not to decorate an application.

## Workflow

- Identify the unknowns that materially affect fit or delivery.
- Prefer primary sources and connected first-party data when available.
- Capture source provenance for claims that may enter a proposal or deliverable.
- Distinguish verified facts from reasonable inference.
- Stop when the remaining uncertainty no longer changes qualification or execution planning.

## Output

Return decision-relevant findings, unresolved unknowns, source quality, and the capabilities or requirements affected by each finding.
